OCS Inventory NG & GLPI — Gestion de parc & Helpdesk

Infrastructure IT · Active Directory · Service Desk

📄 Documentation PDF

Conception et déploiement d'une infrastructure complète de gestion de parc informatique et de helpdesk, de l'installation des serveurs jusqu'à l'intégration avec l'Active Directory. Projet structuré en quatre étapes progressives couvrant inventaire, ticketing, authentification centralisée et supervision automatisée.

OCS Inventory NG Stack LAMP (Apache2, MariaDB, PHP), modules Perl/PHP, agents déployés sur Windows, Linux et Android
GLPI 10 Installation complète, extensions PHP, sécurisation SSL avec certificat auto-signé, accès par nom de domaine
Active Directory Liaison LDAP avec contrôleur de domaine Windows Server, importation des utilisateurs, authentification centralisée
Tickets & Notifications Config SMTP, collecteurs IMAP (Zimbra), alertes automatiques, plugin FusionInventory + planification cron

pfSense — Firewall & Authentification Centralisée AD

Firewall · PKI · LDAPS · Active Directory

📄 Documentation PDF

Configuration et intégration d'un firewall pfSense avec authentification centralisée via Active Directory, en mettant en place une connexion LDAP sécurisée (LDAPS). Le projet couvre le diagnostic réseau, la mise en place d'une infrastructure PKI, la sécurisation TLS et l'intégration complète des utilisateurs AD dans l'interface d'administration pfSense.

Diagnostic LDAP/LDAPS Vérification connectivité ports 389 et 636 via ldp.exe, analyse de trafic Wireshark pour identifier les problèmes de certificat
PKI — AD CS Installation du rôle AD CS sur Windows Server, création d'une AC racine d'entreprise (HERMES-CA), chiffrement RSA 4096 bits / SHA256
Sécurisation LDAPS Export certificat X.509 DER, import dans le Certificate Manager pfSense, établissement du handshake TLS
Intégration AD / pfSense Authentifications LDAP et LDAPS sur pfSense, gestion des groupes et privilèges, connexion des utilisateurs AD à l'interface admin
